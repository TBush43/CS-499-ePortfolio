Course Outcomes

The code review and narratives explain my design decisions. The enhanced app demonstrates software structure, an explainable ranking algorithm, and relational data storage. Input checks and backup exclusions show progress on privacy and security, while the prototype's missing sign-in and encryption remain important limitations.
