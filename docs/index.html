About Me

This ePortfolio will be updated during the course. It will include my code review, my original and enhanced artifact, my enhancement narratives, and my final professional self-assessment.

Capstone Artifact

For my capstone, I plan to enhance my OnWeight Android project from CS 360. The original app was a basic weight-tracking prototype. My goal is to turn it into a more complete coaching app for tracking students, notes, attendance, goals, and follow-up needs.

Planned Enhancements

  • Software Design and Engineering: clean up the app structure and separate the screens, logic, and data layer.
  • Algorithms and Data Structures: add a simple follow-up ranking feature to help decide which students need attention first.
  • Databases: add local data storage for students, notes, attendance, and goals.
