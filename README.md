# CS 499 Computer Science ePortfolio

This repository contains Thomas Bush's CS 499 capstone ePortfolio. The portfolio documents the enhancement of the original **OnWeight** Android application into **OnWeight: Jiu-Jitsu Coach Edition**, a private coaching workspace for student profiles, session notes, attendance, goals, and follow-up decisions.

## Portfolio

The GitHub Pages site will be published at:

<https://tbush43.github.io/CS-499-ePortfolio/>

The site source is located in [`docs/`](docs/).

## Capstone enhancement areas

1. **Software engineering and design** - Refactor the activity-based Java prototype into a layered, testable Android architecture with ViewModels, repositories, reusable UI components, validation, and automated tests.
2. **Algorithms and data structures** - Create an explainable coach-attention ranking feature using hash maps and a bounded priority queue, supported by complexity analysis and deterministic tests.
3. **Databases** - Add a Room/SQLite data layer for students, session notes, attendance, and goals using relationships, indexes, transactions, schema migrations, and privacy controls.
